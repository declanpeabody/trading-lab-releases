Automatic updates
Checks run shortly after startup and daily. When enabled, signed releases install at weekends or between 5pm and 8am New York time. The Mac must be awake, online and running the service. This authorises future signed releases, including strategy changes; it does not mean each change has had a separate human review.
Installation backs up the bot and paper account, restarts, checks the new version and attempts rollback if startup fails. Failed or interrupted releases are never retried automatically. You can still check and install manually.


Connect the release channel
This needs a public GitHub release repository and its trusted RSA public key from the publisher. The channel is pinned after setup. Never paste a private key or GitHub token.
Dashboard installation is available only in the Mac setup. Internet access is needed for checks and downloads. An interrupted installation may require manual recovery; retain the updates folder and its backups.
