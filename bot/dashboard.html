Scanner coverage

All 30 watchlist stocks are ranked from completed daily bars. Score = 20-session return divided by daily volatility, with a 1% volatility floor. Trend and volume filters must pass. Fresh quotes are checked for holdings and the top six unheld candidates. The first daily download takes several minutes; later cycles reuse it. Missing watchlist histories block new entries but allow held-stock checks.

Waiting for the first regular-hours scan.

Local API attempts are capped at 500/day for scanning and historical research, with 200 more reserved for held-stock checks. Other apps using your key are not counted. Exhausting the provider quota can still stop all monitoring. New historical tests share the watchlist, ranking and position limits; intraday decisions remain approximated.
